# Jiangsu Yuren Group - Professional Website

A modern, professional website for Jiangsu Yuren Group, a leading manufacturer of military and police equipment since 1990.

## Features

- **Multi-language Support**: 8 languages (Chinese, English, Japanese, Korean, French, German, Spanish, Russian)
- **Responsive Design**: Fully responsive for mobile, tablet, and desktop
- **Professional Design**: Modern, clean design with military/professional aesthetic
- **Complete Product Catalog**: Tactical boots, military boots, uniforms, knitwear, and technical fabrics
- **SEO Optimized**: Proper meta tags, semantic HTML, and structured content
- **Accessibility**: WCAG compliant with proper ARIA labels and semantic markup
- **Performance**: Optimized CSS and JavaScript, no external dependencies except Google Fonts

## Pages

1. **index.html** - Homepage with hero section, product showcase, features, and trust badges
2. **products.html** - Complete product catalog
3. **shoes.html** - Footwear category page
4. **shoes-tactical.html** - Tactical boots detail page with specifications
5. **shoes-military.html** - Military boots detail page with specifications
6. **uniforms.html** - Professional uniforms product page
7. **about.html** - Company history and mission/vision
8. **manufacturing.html** - Manufacturing capabilities and certifications
9. **contact.html** - Contact form and company information

## Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS variables and Grid/Flexbox
- **Vanilla JavaScript** - No frameworks, pure JS for i18n and interactions
- **Tailwind CSS** - CDN-based utility classes (via custom CSS)
- **Google Fonts** - Noto Sans SC (Chinese) and Inter (English)

## Internationalization (i18n)

The website supports 8 languages with a simple i18n system:
- Chinese (中文)
- English
- Japanese (日本語)
- Korean (한국어)
- French (Français)
- German (Deutsch)
- Spanish (Español)
- Russian (Русский)

Language preference is saved to localStorage and persists across sessions.
